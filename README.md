# Repositorio de ejercicios con Makefile

Este repositorio reúne ejemplos prácticos para comprender el uso de **Makefiles** como herramienta de automatización en proyectos de programación.

El objetivo general del repositorio es mostrar cómo un Makefile permite organizar y ejecutar de forma sencilla tareas repetitivas como:

- compilar código fuente;
- generar archivos ejecutables;
- ejecutar programas;
- producir archivos de salida;
- limpiar archivos generados;
- automatizar flujos completos con un solo comando.

Dentro del repositorio se incluyen dos proyectos documentados de manera individual, cada uno con su propio archivo README donde se explica con mayor detalle su funcionamiento, estructura, comandos disponibles y uso del Makefile.

## Documentación disponible

### 1. [README del ejemplo del conjunto de Julia](https://github.com/Champagnepagcois/makefile/blob/main/Ejemplo_julia/README.md)

Este README explica el ejemplo basado en el **conjunto de Julia**, un fractal generado mediante código en C++ y visualizado con GNUplot.

En este proyecto, el Makefile automatiza el proceso de compilación, ejecución del programa, generación del archivo de datos y creación de la imagen del fractal.

Consulta este archivo para entender el ejemplo visto en clase y cómo se organiza su flujo con `make`.

### 2. [README de mi ejemplo de Fibonacci](https://github.com/Champagnepagcois/makefile/blob/main/Mi_makeFile/README.md)

Este README documenta mi propio ejemplo, basado en la **secuencia de Fibonacci**.

En este proyecto, el programa calcula los primeros términos de la sucesión, guarda los resultados en un archivo de texto y genera una gráfica con GNUplot.

Consulta este archivo para ver cómo apliqué la estructura de un Makefile en un proyecto propio, reutilizando la idea de automatizar compilación, ejecución y generación de resultados.

## Propósito del repositorio

El propósito principal de este repositorio es servir como evidencia y práctica del uso de Makefiles, mostrando tanto un ejemplo base como una implementación propia.

De esta forma, cualquier persona que revise el repositorio puede entrar primero a este README general y después dirigirse al README específico que quiera consultar:

- el README del ejemplo de Julia;
- el README del ejemplo de Fibonacci.

Cada README contiene instrucciones más detalladas para ejecutar el proyecto correspondiente y comprender cómo funciona su Makefile.
